# SmileCare Dental Clinic

Одностраничный сайт вымышленной стоматологической клиники SmileCare с ассистентом на Gemini. Ассистент отвечает только по базе знаний клиники, не ставит диагнозы и помогает собрать запись: имя, услугу и удобное время.

Сайт написан на JavaScript: Next.js и React. Ключ Gemini читается только на сервере из переменных окружения.

## Требования

- Node.js 22 или новее
- Ключ Gemini из [Google AI Studio](https://aistudio.google.com/apikey)

## Локальный запуск

```bash
npm install
copy .env.example .env
```

Откройте `.env` и вставьте свой ключ:

```bash
GEMINI_API_KEY=ваш_ключ
GEMINI_MODEL=gemini-3.5-flash-lite
```

Затем:

```bash
npm run dev
```

Сайт откроется на [http://localhost:3000](http://localhost:3000).

Не коммитьте `.env`: файл уже указан в `.gitignore`.

## Деплой на Vercel

1. Импортируйте проект в [Vercel](https://vercel.com/new). Платформа сама определит Next.js, отдельный `vercel.json` не нужен.
2. В настройках проекта выберите Node.js 22.
3. Добавьте переменные окружения:
   - `GEMINI_API_KEY` — ключ из Google AI Studio
   - `GEMINI_MODEL` — `gemini-3.5-flash-lite` (можно не задавать, это значение по умолчанию)
4. Запустите деплой.

Маршрут `POST /api/chat` выполняется на сервере. Ключ в браузер не попадает: переменная без префикса `NEXT_PUBLIC_`.

## Как устроен ассистент

- Факты клиники лежат в `lib/knowledge.js` и одновременно показаны на странице.
- `lib/prompt.js` собирает из них системную инструкцию.
- `app/api/chat/route.js` отправляет диалог в Gemini и проверяет заявку: услуга должна быть из прайса, время — в графике работы и в будущем.
- Подтверждённая заявка получает номер вида `SM-4821` и остаётся в ответе чата. Отдельной базы записей нет: на Vercel файлы между вызовами не сохраняются.

## Скрипты

- `npm run dev` — локальная разработка
- `npm run build` — продакшен-сборка
- `npm start` — запуск собранного сайта
